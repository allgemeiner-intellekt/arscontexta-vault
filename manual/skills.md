# Skills

## Processing

| Command | What It Does | When to Use |
|---------|-------------|-------------|
| `/distill` | Extract atomic ideas from source material into notes | After dropping raw material into inbox/ |
| `/connect` | Find links between notes, especially across domains | After creating new notes, or periodically |
| `/revisit` | Return to old notes with new understanding | When new context enriches old ideas |
| `/verify` | Check quality: description, links, schema, discovery | After creating or updating notes |
| `/validate` | Schema validation across the vault | Periodic health check |

## Orchestration

| Command | What It Does | When to Use |
