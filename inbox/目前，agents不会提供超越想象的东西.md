## 目前，agents不会提供超越想象的东西

关于AI，一个值得思考的问题或许是，要不要给它远远超过我的阅读能力的材料。某种意义上这是伪命题，大语言模型本来就比任何人知道更多东西。当然，从上下文给东西和从训练数据给东西是不一样的，大语言模型都是“产品”，其能够发挥作用，依靠很多训练。用户面对的是最终的产品，能控制的是从上下文给的东西

所谓大量上下文，其实就是“记忆”

**Nowledge Mem v0.6** 是一款主打“主动式知识（Proactive Knowledge）”的本地优先、基于图谱增强的个人上下文管理器与记忆层。解决使用多个孤立的 AI 工具（如 ChatGPT、Claude、Cursor 等）（和笔记软件）导致知识和上下文碎片化的问题。作为一个中立、安全且完全本地化的记忆中枢，能将所有的 AI 工具连接起来，并自动整理知识。

问题在于：

我需要记住我忘了的东西吗？AI辅助下的记忆，与笔记不同，它可以记住我完全忘了的东西。这可以说是历史上从未有过的东西。“记住忘了的东西”究竟意味着什么？
- 将“遗忘”的选择权从生物本能（自然忘记），交还给了人类的理性（审查后决定废弃）。
- "记得"从未知道过的东西。

某种意义上，大语言模型到目前为止从来没做到过超出人的想象的事，而我们一直在假设大语言模型可以在某些事情上给出超出我们想象的效果

Coding Agent 的卓越表现让人们误以为 Agent 在所有领域都具有同等强大的能力。编程语言具有严密的逻辑、确定性语法和严格约束，这种"人造语言"的特性为AI提供了清晰的边界和可预测的模式。

根本上，在由agent辅助的情况下，我看不到“记住我忘了的东西”能带来什么真正的好处，因为agent并不会提供超越想象的东西
