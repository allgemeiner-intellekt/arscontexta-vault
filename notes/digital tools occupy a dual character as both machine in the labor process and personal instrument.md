# digital tools occupy a dual character as both machine in the labor process and personal instrument

Marx distinguishes between the tool (Werkzeug) — an instrument subject to the worker's will, extending individual capacity — and the machine — an apparatus within which the worker serves as an operative, subordinate to the machine's rhythm and logic. This distinction becomes complex in the case of digital tools, which occupy both positions simultaneously.

The personal computer, and by extension the LLM, is experienced by the individual as a personal instrument. The user deploys it to extend their cognitive capacities — to write better, to research faster, to generate ideas. This is the experience of tool-use: the object serves the subject. The experience is genuine; the tool does extend individual capacity.

But the same object is simultaneously a machine in the social labor process. The computer's use generates data that improves advertising algorithms, trains behavioral models, and feeds into corporate productive processes. The LLM's use generates interaction data that improves future model iterations. The individual who experiences the tool as personal instrument is also functioning as an operative within a larger productive apparatus — one they do not own and one whose outputs they do not control.

This dual character is not a contradiction to be resolved through better design or clearer categorization. It is a structural feature of how digital tools exist under capitalism. The same object has both determinations because the social relations of production have made it so. The same keystrokes that extend the individual's capacity simultaneously contribute to capital's productive accumulation.

What the dual character clarifies: individual resistance framed as "reclaiming" the personal-instrument dimension cannot escape the machine dimension, because the two exist in the same object under the same social relations. The personal and the collective, the liberating and the exploitative, coexist in every use.
