# cost friction in AI use suppresses the iterative refinement that actually develops prompt skill

When using AI carries a real or perceived cost per interaction, the natural tendency is to front-load effort into making each prompt "correct" on the first try. This minimizes the number of exchanges. But it also minimizes the learning loop. The prompt that succeeds on the first attempt teaches you nothing about what your model of the task was missing.

Conversely, when cost friction disappears — through free access, reverse-proxied APIs, or simply a change in attitude — the interaction pattern shifts. You write, observe the AI's response, diagnose what the response reveals about your prompt's gaps, revise, and repeat. Five or six iterations of this produces a prompt that is genuinely better, and a mind that understands the problem more clearly.

The irony is that "wasting" attempts is the mechanism by which prompt skill develops. Cost friction that discourages wasted attempts also discourages learning.
