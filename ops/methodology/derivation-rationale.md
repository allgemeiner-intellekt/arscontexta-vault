# derivation rationale for allgemeiner intellekt

This knowledge system was derived for an intellectual practice centered on critical thinking across disciplines. The user reads and thinks broadly — Marx and political economy, German classical philosophy (Kant, Hegel), phenomenological traditions, mainstream and heterodox economics, Chinese and world history, and the rapidly developing field of AI. The reference to Marx's concept of "allgemeiner Intellekt" (general intellect) from the Grundrisse's Fragment on Machines signals the nature of the practice: not academic research for institutional output, but building a comprehensive critical apparatus for understanding the world.

## Key Dimension Choices

**Atomic granularity** was chosen because the intellectual material — dense philosophical arguments, economic theories, historical observations — naturally decomposes into discrete propositions. A chapter of the Grundrisse contains many distinct ideas, each of which may connect to entirely different domains. Atomic notes enable these cross-disciplinary links.

**Flat organization** was chosen because the practice is fundamentally cross-disciplinary. A hierarchical folder structure (philosophy/, economics/, history/) would impose artificial boundaries on ideas that connect freely. Hegel connects to Marx connects to AI — folders would fragment these connections.

**Explicit + implicit linking** was chosen because the user's current system relies entirely on mental recall: "if I can recall them, they exist." Explicit wiki links externalize known connections. Semantic search enables discovering connections the user has not yet made — the key value proposition of this system.

**Heavy processing** was chosen because the source material (Grundrisse, phenomenological texts, economic theory) is dense and rewards careful extraction. Light processing would miss the nuance that makes these ideas worth capturing.

**3-tier navigation** was chosen because the breadth of the terrain — at least four major domains plus emerging interests — requires layered maps to remain navigable. A 2-tier structure would flatten too much.

**Self-space enabled** because persistent agent memory serves an intellectual practice where continuity across sessions matters. The agent should remember what it is working on and what connections it has been building.

**Personality not derived** — the user showed no strong personality preference signals. Neutral-helpful default is appropriate for serious intellectual engagement.

## Platform and Automation
Claude Code with full automation. The user is comfortable with AI tools and described using AI to convert articles to markdown. The full pipeline — processing, maintenance, semantic search — is available from day one.

## Coherence Notes
No hard or soft constraint violations. Atomic + heavy processing + 3-tier navigation + semantic search is a naturally coherent configuration for broad intellectual work. Semantic search compensates for potential orphan drift in a flat atomic system.
