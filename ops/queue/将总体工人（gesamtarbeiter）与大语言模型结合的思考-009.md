# Claim 009: Claude Code's evolution from tool to machine mirrors the historical transition from craft to industrial machinery

Source: [[将总体工人（Gesamtarbeiter）与大语言模型结合的思考]] (lines 34-38)

## Distill Notes

Extracted from 将总体工人（gesamtarbeiter）与大语言模型结合的思考. This is a CLOSED claim.

Rationale: The source uses Claude Code as a concrete case study: early versions were legible tools — users could immediately see the affordances and use them intentionally. Later versions automate background operations, become less transparent, and expand in ways that no longer invite intentional use but instead run autonomously. This mirrors the Marxist analysis of industrial machinery displacing craft: the worker's skill and intention get absorbed into the machine's mechanism. The increasing opacity and automation of Claude Code is not a design failure but a structural tendency.
